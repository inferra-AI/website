# inferralab.com

The public website for Inferra: static HTML/CSS, no build step. Design and
decisions: `docs/design/landing-page.md` in the inferra repo (branch
landing-site); Figma page "Inferra · Landing v2".

Preview locally: `cd site && python3 -m http.server 8765`.

Lines marked `LAUNCH:` must be replaced with live values before going public
(demo commit, API host, video).

Website privacy

How Inferra uses optional, cookieless Umami analytics and respects Do Not Track.

Website analytics

When configured, Umami records page views, referring sites, campaign parameters and actions such as opening the demo or calculating pricing. Reports are aggregated. It uses no cookies and collects no personal data. We do not send app logs, secrets, repository contents or calculator input values.

Do Not Track is respected: when your browser sends that preference, this site does not load analytics or send events. Analytics also stays off when our configuration is empty.

Fonts are served from this site. Hosting infrastructure receives ordinary web requests, including network information such as an IP address.

When you follow a link

GitHub sign-in, the Inferra platform, downloads and the GitHub issue tracker are separate from this static website. For questions about this website, open an issue without private information.

Website privacy

The inferralab.com static website collects no analytics today. If analytics is enabled later, it will be first-party and cookieless.

What this website collects today

We do not collect analytics through this website today. It has no configured analytics endpoint, advertising pixels, session replay, tracking cookies or signup form that stores your information. Fonts are served from this site. The homepage may request the public status summary from our status page.

The static site is hosted on GitHub Pages. Hosting infrastructure receives ordinary web requests, including network information such as an IP address; this statement about our site’s analytics does not mean the host receives no request data.

If analytics is enabled later

Any future site analytics will be first-party and cookieless. It will measure site use, not app logs, environment variables or secret values. We will update this page when collection is enabled.

When you follow a link

GitHub sign-in, the Inferra platform, downloads and the GitHub issue tracker are separate from this static website. An MCP early-access issue is public, including any optional email address you choose to include. For questions about this website, open an issue without private information.

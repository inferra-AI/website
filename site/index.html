How it works

The diff is your infrastructure.

main deploys to prod. Every other branch gets its own preview copy, removed with the branch. A database declared next to an app appears beside it, its address already in the app’s environment, reachable by that app and nothing else.

.inferra/org.yaml+5 −0
spaces: prod: { branch: main } stage: {} preview: { branches: "*" } apps: api: path: api/ services: orders: type: postgres version: "17" worker: path: worker/ services: { orders: {} }

Application and data belong together

A database only its apps can reach.

Declare Postgres, a Valkey cache or an S3 bucket next to the apps that use it. Inferra creates it in the same space, puts its address in those apps’ environment, and closes it to everything else.

Choose the Postgres major version in org.yaml. If you delete a database, support can restore it within 7 days.

Security

Built to run other people’s code.

A sandbox around every app

Every app runs in a gVisor sandbox on every plan, Free included.

Each space is its own network

Closed by default. Apps in a space reach each other; nothing reaches private ranges or cloud metadata.

Builds from a pinned catalog

Buildpacks come from a mirrored catalog pinned by digest. No Dockerfile needed.

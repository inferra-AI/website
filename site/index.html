Questions, answered.

Inferra in plain words.

What is Inferra?

Inferra is the Git-native cloud: a PaaS that builds APIs, web apps and background workers from GitHub pushes with Cloud Native Buildpacks and runs them with managed Postgres, a Redis-compatible Valkey cache and S3 buckets. Connect a GitHub repository and push; Inferra runs the servers, HTTPS, scaling and patching.

How is Inferra different from Vercel?

Vercel is built mainly for frontend frameworks and functions, which have a maximum duration and scale down without traffic, so always-on workers don’t fit. Its Postgres comes from partners such as Neon. Inferra runs long-running services and background workers with Postgres, a cache and buckets in the same place, with prepaid credits at AWS cost plus 30%. See the full comparison at inferralab.com/compare.

Is Inferra a Heroku alternative?

Yes. Like Heroku, you deploy with git push and buildpacks, with managed Postgres. Inferra adds previews for every matched branch, a gVisor sandbox around every app, built-in S3 buckets, and prepaid credits at AWS cost plus 30%.

Do I need a Dockerfile or Kubernetes knowledge?

No. Buildpacks detect your language and build a secure image from source. Inferra runs the servers, clusters, HTTPS, scaling and patching, so you only maintain your code.

Which languages and frameworks are supported?

Node.js, Python, Go, Java, Ruby, PHP, .NET and static sites, plus any app with a Procfile.

Can I run background workers?

Yes. A Procfile worker selected in the branch file runs as a long-running background worker, next to your web apps and sharing their databases.

How does pricing work?

You pay for the CPU, memory and storage you reserve for each branch, at our AWS cost plus 30%, from prepaid credits. The first $5 every month is free per account, shared across its repos. A card on file is never charged unless you buy credits, and the bill can never go above the credits you added.

How are apps isolated and secured?

Every app runs in its own gVisor sandbox, including apps covered by free usage. Each environment is a private network, and a database accepts connections only from the apps that use it.

Does Inferra work with AI coding assistants?

Yes. Inferra’s MCP server connects Claude Code, Codex, Cursor and VS Code to your apps: they read logs and metrics to explain problems, and propose configuration changes as pull requests you review.

Questions, answered.

Inferra in plain words.

What is Inferra?

Inferra is a platform for running web apps, APIs and background workers from a GitHub repository.

Which languages and frameworks are supported?

Node.js, Python, Go, Java, Ruby, PHP, .NET and static sites. Inferra detects your language and builds from source. A Procfile is a short file that names the commands used to start your app.

What is a background worker?

A background worker is a process with no public web address, such as a queue consumer. Set run.process: worker in your branch file to run one.

Can my app connect to services outside Inferra?

Yes. Apps can connect to the public internet. Store credentials as secrets and allowlist our fixed outbound IP addresses, listed in the docs/dashboard and shared by all apps on the platform. Connections to private networks in your own cloud are coming later.

Can I run my own database or queue?

Yes. Bring your own Docker image (BYOD) to run services such as MongoDB or RabbitMQ, with environment settings and secrets. These services are not backed up. Choose managed Postgres if you need backups and restore to any point in the past 7 days.

What happens when my credits run out?

At $0, new deployments pause. After a 3-day grace period, running apps and services pause; data is kept for 7 days. Add credits to resume. A card on file is only charged when you buy credits or enable optional auto top-up.

What can my AI assistant change?

MCP is a connection that lets an AI assistant use Inferra’s tools. The tools are read-only: assistants inspect apps, logs and metrics and suggest configuration changes. You review any proposed changes in your repository.

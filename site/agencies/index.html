Inferra · Guide

Inferra for agencies and client projects

Keep client repositories separate, share branch previews for review, and plan prepaid credits with clear account ownership.

One org per client repository

An org is the Inferra project connected to one GitHub repository. Keep each client’s code in its own repo and configure members with the access that client needs. Repository admins also have owner access.

A preview namespace for client review

Declare feature/* in org.yaml. Each matched branch gets its own preview namespace: a separate running environment with its own private network and bound services. Share the app’s HTTPS address for review. Each app runs isolated with gVisor; previews do not automatically copy production database data.

Use synthetic review data, register preview callback URLs and remove finished branches. Each open branch reserves its own resources.

Plan prepaid credits for each client

Prepaid credits belong to a GitHub account and are shared across that account’s repository orgs. There is no separate per-org wallet. For an independent client balance, use the client’s owning account and wallet; several client repos under your account share your credits and monthly free allowance. Branch quotas limit reservations but do not divide the wallet.

Pay for what you reserve from prepaid credits: CPU $16.19/vCPU-month, memory $1.78/GB-month, storage $0.104/GB-month. Postgres backups are $0.0299/GB-month, free for accounts that never bought credits. The first $5 of usage is free every month per account; a card is required. The bill cannot grow beyond what you prepaid.

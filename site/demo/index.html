The public demo

The Inferra demo repository will show an API, a worker and Postgres deployed from GitHub. The live demo goes live with the demo video; it is not running yet.

The demo goes live with the video

The public repository is inferra-AI/inferra-demo. The Inferra App has not yet been installed on it. Installation and the first deployment will be recorded; there is no live app or public dashboard to link here yet.

The video, live app and read-only public dashboard are coming soon. This page does not show simulated deployment results.

What the recording will show

  1. Install the App and commit the org configuration for an API and a worker.
  2. Push, read the real commit statuses and open the deployed API.
  3. Add Postgres, bind it to the API and inspect which apps rebuild.
  4. Break a health check, read the evidence in logs and roll back.
  5. Inspect the same org in the dashboard.

Browse the repository’s commits or visit the status page. For your own deployment, use the setup guide.

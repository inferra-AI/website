Demo

A real deploy, start to finish

One line changed in the public inferra-AI/inferra-demo repository, pushed with git, built with buildpacks and live on Inferra. Recorded on our dev platform; only the build wait is cut.

See it yourself

  • The repository: an API, a background worker and the .inferra/ files.
  • The live API: it answers with the greeting from the last push.
  • The read-only dashboard: apps, deployments, logs and metrics of the demo org.
  • The status page: checked from outside every five minutes.

What happens in the video

  1. One line in api/server.js changes; git commit and git push.
  2. GitHub tells Inferra about the push; the commit shows a check per app.
  3. Inferra builds the API with buildpacks (no Dockerfile) and the new version replaces the old one.
  4. The API answers over HTTPS with the new greeting.

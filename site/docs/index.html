Inferra is the Git-native cloud: a PaaS that builds APIs, web apps and background workers from GitHub pushes with Cloud Native Buildpacks and runs them with managed Postgres, a Redis-compatible Valkey cache and S3 buckets. Start with one setup guide, then use the configuration and CLI references for precise details.

Two files, a Git push, then evidence

Install the GitHub App on a repository and commit .inferra/org.yaml v2 and a file for each branch’s settings. A push to a mapped branch builds and deploys the applicable apps. Read the result on the commit, in the dashboard or through the CLI. Databases and caches accept connections only from their bound apps.

Each matched branch gets its own space and bound service instances. Org rules and branch quotas come from the default branch; build and runtime settings come from that branch’s pushed commit. Use the MCP server to inspect deployment evidence with your assistant.

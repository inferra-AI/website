Inferra is the Git-native cloud: a PaaS that builds APIs, web apps and background workers from GitHub pushes with Cloud Native Buildpacks and runs them with managed Postgres, a Redis-compatible Valkey cache and S3 buckets. Start with one setup guide, then use the configuration and CLI references for precise details.

Two files, a Git push, then evidence

Install the GitHub App on a repository and commit .inferra/repo.yaml and each app folder’s .inferra/app.yaml, both version: 3. A push to a mapped branch builds and deploys the applicable apps. Read the result on the commit, in the dashboard or through the CLI. Databases and caches accept connections only from their bound apps.

Each matched branch gets its own app space. Account services can be attached to multiple branches, sharing the same data. Repo rules and branch quotas come from the default branch; app settings come from the deployed branch. Use the MCP server to inspect deployment evidence with your assistant.

Metrics and logs

Inspect resource use, HTTP performance and live logs for an app in its branch namespace.

Read the charts

Open the repository org → namespace → app → Metrics. Choose 15m, 1h, 6h, 24h or 7d. The initial range is 1h. Auto refresh offers Off, 15s, 30s and 1m, initially 30s. Choosing a range up to 1h selects 30s refresh; longer ranges select Off. Refresh pauses while the browser tab is hidden.

CPU and memory show separate lines for instances when instance samples are available, otherwise the aggregate series. A dashed memory limit line appears when a configured limit and aggregate memory samples are available. Restart markers show increases in an instance’s restart count.

HTTP charts show requests per second, p50 and p95 latency, and the fraction of requests returning 5xx. A chart appears only when its series has data. If all charts lack data, the panel says No metrics available. Missing HTTP charts are not proof of zero traffic; samples may be unavailable.

Zoom into a time window

  • Use the mouse wheel to zoom around the pointer.
  • Drag-select a time interval to zoom into it.
  • Hold Shift and drag to pan.
  • Pinch with two pointers to zoom.
  • Focus a chart and press + or - to zoom; use the left and right arrows to pan.

Charts share the selected time window. Auto refresh is Paused while zoomed. Choose Reset zoom or Resume to return to the moving time range.

Follow live logs

Open the app’s Logs tab. Choose 15 min, 1 h, 6 h or 24 h of history. Filter by source, instance, stdout/stderr, warnings and errors, or search text. The viewer keeps up to 2,000 lines and drops the oldest lines as new ones arrive.

Choose Live to stream new lines; the button changes to Live on. Choose it again to stop streaming. The view follows new lines while you are at the bottom. Scrolling upward pauses following while live lines still arrive. Jump to latest restores following and shows the pending-line count.

Use the CLI

inferra target shop/main
inferra logs api --follow
inferra logs api --since 15m --grep error --instance 0
inferra metrics api --since 6h
inferra metrics api --since 168h --json

Logs default to at most 500 recent lines without follow. Use --limit to change that and --since for a duration or RFC 3339 time. Metrics default to 1h; use 168h for seven days. Metrics prints a snapshot with resource use, request and latency summaries and sparklines; it has no follow flag. See all commands and flags.

CLI reference

The Inferra CLI inspects repository orgs and operates running workloads. GitHub pushes deploy source; customer commands cover logs, metrics, instances, rollback and promotion.

Customer commands

Run inferra COMMAND --help for built-in help. Replace uppercase placeholders with your names. These are customer commands; operator-only and planned command surfaces are excluded.

Command (after inferra)Purpose
versionPrint the installed CLI version.
init [-p PATH] [--name NAME] [--force]Write starter configuration and environment workflow. Review the release-specific workflow behavior in setup. --force overwrites generated files.
login --api https://api.dev.inferralab.comPaste a personal token from Settings → Tokens. --token - reads stdin; --org and --space choose the target.
logoutClear the saved login locally.
whoamiShow the current identity and roles.
target [ORG[/SPACE]]Show or save the default target.
orgsList accessible repository orgs.
orgs delete ORG [--yes]Delete an org and all its resources. Restricted by the API to org-wide owners (repository admins); prompts for confirmation unless --yes is passed. Removing repository access in GitHub also triggers cleanup.
org [NAME]Inspect an org; defaults to the target.
spacesList spaces in the target org.
accountsList accessible GitHub accounts and pooled plan usage.
account NAMEShow one account’s orgs and shared usage.
quotasList available plans and limits.
quota PLANShow one plan’s limits.
usageShow target org usage and quota.
membersList members and roles.
invitationsList join requests; invitations accept ORG and invitations decline ORG answer them.
events [--app APP] [--since DURATION_OR_TIME]Read org events; --since accepts a duration such as 24h or an RFC 3339 time.
appsList apps in the target space.
apps status NAMEShow an app and its status.
instances APPInspect running instances.
deployments APPList deployment history.
logs APPRead app and platform logs. --follow/-f streams; --since filters time; --limit defaults to 500; --instance selects an instance; --grep filters text.
metrics APP [--since 1h]Read CPU, memory, requests, latency and restarts. Default 1h; write 168h for 7 days.
exec APP [--pod POD] -- COMMAND...Run a command in a running instance; defaults to a shell and the first ready pod.
start APPStart a stopped app.
stop APPStop instances, preserving the URL, configuration and services.
restart APPRestart using the same image.
rollback APP [--to DEPLOYMENT_ID]Redeploy an earlier image with current variables and secrets.
promote APP --from SPACE [--to SPACE] [--deployment ID]Promote the source space’s live image or a specified deployment; destination defaults to the targeted space.
env APP [--reveal]List variables. Developers and owners may reveal ordinary values. Managed-service connection values stay hidden.
secrets APPList secret names and metadata; never values. Customer tokens have no secret-writing CLI commands.
buildpacksList curated buildpack IDs, versions and status.
servicesList services and their bindings in the target space.
service status NAMEInspect service health, version and backup metadata when available. db status NAME is the database form.
service logs NAMERead service logs. db logs NAME is the database form. Both support --follow/-f, --since, --instance and --grep.

Flags and environment

SettingPurpose
--api / INFERRA_APIAPI address; flag takes precedence, then environment, then saved login. Use https://api.dev.inferralab.com during preview.
--org / INFERRA_ORGOrg target; flag overrides environment and saved target.
--space / INFERRA_SPACESpace target; flag overrides environment and saved target.
--jsonMachine-readable output on commands that implement it.
INFERRA_TOKENPersonal token for automation; overrides the saved token. Do not put the value into a command argument or commit it.
INFERRA_CONFIGOverride the local configuration file path.

When INFERRA_TOKEN is set, login refuses to replace it. Unset it to use another saved login. The explicit preview API is required because the current built-in default is incorrect.

Inspect and operate

inferra login --api https://api.dev.inferralab.com
inferra orgs
inferra target YOUR_ORG/prod
inferra logs api --since 15m
inferra metrics api --since 1h
inferra exec api -- /bin/sh
inferra rollback api
inferra promote api --from prod --to stage

What changes where

Push to GitHub to deploy new source. Edit org.yaml to change resources, app definitions, membership or service bindings. Use GitHub Environments for ordinary runtime variables and the dashboard for Inferra-set secret values. A manual rollback selects an image, not historical configuration.

The selected-secret generator’s --secret and --workflow-only flags are coming soon in a confirmed CLI release; see setup’s release note. Custom domains and MCP are also coming soon.

Inferra · Documentation

CLI reference

Commands and flags as printed by the CLI, grouped by task.

Start here

GitHub pushes deploy source. The CLI inspects apps and operates running workloads. Choose a target with inferra target ORG/SPACE; use --org and --space to override it for one command. Commands also accept the global flags printed below.

inferra login
inferra target shop/main
inferra apps
inferra logs api --follow

This reference preserves every command and flag in the supplied CLI help capture. Some help still describes plans or v1 services; credits mode uses the wallet, and v2 declares services in org.yaml with bindings in branch files. Read credits and quotas and the v2 reference for those distinctions.

Init currently writes version 1

inferra init currently generates the version-1 org file. To use v2, write these two files yourself, with your source in a named folder such as api/:

.inferra/org.yaml on the default branch:

version: 2
apps:
  - folder: api
    branches: [main]

.inferra/main.yaml on main:

apps:
  api:
    run:
      instances:
        min: 1
        max: 1
      cpu: "0.25"
      memory: 256Mi

Commit both and push. See the configuration reference for services, secrets and more branches. --workflow-only generates a workflow from an existing org.yaml; it does not convert a v1 file to v2.

Command list and global flags

inferra

Find the available commands and global flags.

$ inferra --help
Inferra deploys repositories connected through the Inferra GitHub App.
Use the CLI to inspect apps and operate running workloads.
Start with: inferra init, commit the generated files, and push to GitHub.

Usage:
  inferra [command]

Available Commands:
  account     Show an account's orgs and pooled resource usage
  accounts    List GitHub accounts and their shared resource usage
  admin       Operator commands for Inferra staff (super admins)
  apps        List apps in the targeted space
  buildpacks  List curated buildpacks
  completion  Generate the autocompletion script for the specified shell
  db          Inspect managed databases
  deployments Show an app's deployment history (newest first)
  env         List an app's environment variables
  events      Show the org's audit log (who did what)
  exec        Run a command in a running app instance
  help        Help about any command
  init        Create starter Inferra repository configuration
  instances   Show an app's running instances
  invitations List and answer org join requests
  login       Log in with a personal token from the web UI (like cf login)
  logout      Remove the saved token from this machine
  logs        Show recent logs, or follow them with -f
  members     List org members and their roles (GitHub admins and org.yaml members)
  metrics     Show an app's CPU, memory, requests and latency over time
  org         Show an org's plan, quota usage, owners and spaces (like cf org; change plans in the web UI)
  orgs        List your GitHub repository orgs and their plans
  promote     Deploy the exact image running in another space (no rebuild)
  quota       Show one plan's limits (like cf quota)
  quotas      List plans and their quotas (like cf quotas)
  restart     Restart instances with the same image
  rollback    Redeploy an earlier deployment (default: the previous one)
  secrets     List an app's secret names (values are never shown)
  service     Inspect a managed service
  services    List services in the targeted space and the apps using them
  spaces      List the org's spaces
  start       Start a stopped app
  stop        Stop all instances (keeps URL, config and services)
  target      Show or set the org and space that commands act on
  usage       Show the org's quota and current usage
  version     Print the CLI version
  whoami      Show who the current token belongs to and your orgs

Flags:
      --api string     API URL (default from $INFERRA_API, saved login, or https://api.inferralab.com)
  -h, --help           help for inferra
      --json           print machine-readable JSON
      --org string     org (overrides the saved target and $INFERRA_ORG)
      --space string   space (overrides the saved target and $INFERRA_SPACE)

Use "inferra [command] --help" for more information about a command.

Login, targeting and repository setup

inferra login

Log in with a personal token. Sign in at the Inferra web UI with GitHub,

$ inferra login --help
Log in with a personal token. Sign in at the Inferra web UI with GitHub,
generate a token under Settings → Tokens, then paste it here. The token
carries your own roles: you can do exactly what you can do in the UI.

Then pick the org and space to work in, like "cf login": chosen automatically
when there is only one, otherwise from a numbered list (skip with --org and
--space). Pipelines don't log in: set INFERRA_TOKEN (plus INFERRA_ORG and
INFERRA_SPACE) instead.

Usage:
  inferra login [flags]

Examples:
  inferra login                                  # paste the token (hidden) when asked
  printenv INFERRA_NEW_TOKEN | inferra login --token - --org acme --space dev

Avoid --token <value>: it shows up in shell history and process listings.

Flags:
  -h, --help           help for login
      --org string     org to target (skips the prompt)
      --space string   space to target (skips the prompt)
      --token string   personal token; "-" reads it from stdin (preferred over passing the value)

Global Flags:
      --api string   API URL (default from $INFERRA_API, saved login, or https://api.inferralab.com)
      --json         print machine-readable JSON

MCP is coming soon

Inferra’s planned MCP server will let assistants read troubleshooting evidence and propose configuration changes as pull requests to org.yaml. It is not available yet.

Coming soon: read the evidence, propose a change

The MCP server is not built. The planned connection targets are Claude, Codex, VS Code and Cursor. There is no connection URL, install command or available tool to configure today.

What it will never do

The intended permission model never allows the assistant to deploy, restart or delete resources, read secret values, or write configuration directly to the platform. Configuration changes can only be proposed as pull requests to org.yaml for you to review and merge. A subsequent Git push follows the normal deployment path.

Authentication, org selection, revocation and detailed audit behavior are still to be implemented. The design calls for access limited by your permissions, explicit org selection and a way to revoke the assistant’s access. These are plans, not shipped controls.

Help shape early access

Tell us which assistant you use and what you want help with. The GitHub issue is public; email is optional. Do not include credentials, secrets or private logs.

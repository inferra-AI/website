Starter templates for Inferra

Start with Next.js and Postgres, a FastAPI worker, or AI chat. Create a repository, connect Inferra and deploy from Git.

Create your own repository first, then install the GitHub App on it. The button starts GitHub’s template flow; it does not deploy until you connect the app and push valid configuration.

Next.js + Postgres

A web app with a managed database. Run Next.js as a Node server; Vercel-only edge features need changes.

  1. Deploy to Inferra
  2. Install the Inferra GitHub App on your new repository.
  3. Review its README, the two configuration files and required secrets, then push and read the deployment checks.

Before deploying

Pay for what you reserve from prepaid credits: CPU $16.19/vCPU-month, memory $1.78/GB-month, storage $0.104/GB-month. Postgres backups are $0.0299/GB-month, free for accounts that never bought credits. The first $5 of usage is free every month per account; a card is required. The bill cannot grow beyond what you prepaid.

Confirm template repository access on GitHub. A template does not waive reservations or supply API-provider credentials. Read the setup guide.
